# 7-inch tablet screenshots

Place up to eight Google Play Store screenshots in this folder.

- Format: PNG or JPEG
- Maximum file size: 8 MB each
- Aspect ratio: 16:9 landscape or 9:16 portrait
- Dimensions: each side must be between 320 px and 3,840 px

Recommended landscape export: `1920 x 1080 px`.

These must be genuine in-app Android tablet captures. Google Play allows up
to eight screenshots for this device class.
