# Apple App Store — 13-inch iPad screenshots

Place 1–10 iPad App Store screenshots in this folder.

- Format: PNG or JPEG
- Portrait: `2064 x 2752 px`
- Landscape: `2752 x 2064 px`
- Use actual in-app iPad captures without promotional text baked outside the
  app interface.

Goldie targets the 13-inch iPad format for this set.
